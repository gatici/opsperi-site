# opsperi-site

Public marketing + legal site for **Opsperi**, served via GitHub Pages at
[https://opsperi.com](https://opsperi.com).

## Pages
- `index.html` — landing page
- `privacy.html` — Privacy Policy (English + Turkish); required for the WhatsApp Business Platform / Meta app review
- `gizlilik.html` — Turkish shortcut that redirects to `privacy.html#tr`

## Hosting
Static site published with GitHub Pages from the `main` branch. Custom domain
configured via the `CNAME` file (`opsperi.com`).
